# Границы и непроверенное

Обязательные функции R01–R15 реализованы; доказательные материалы R16 заполнены.
Автоматическая проверка не подменяет всю ручную приемку.

- Выполнены сборка на Windows, 40 xUnit cases на SQLite и отдельный WPF-сценарий
  с реальными Views, командами, редакторами и проверкой binding errors.
- Ручной полный маршрут T40 с физическим вводом PasswordBox, кликами подтверждений,
  проверкой удобства на разных разрешениях не пройден. Windows Computer Use
  не подключился: `native pipe ... os error 2` после повторов и сброса сессии.
  Регистрация/вход проверены на уровне сервисов; окно входа действительно открывалось.
- Повторное открытие данных проверено новым DatabaseRuntime и сервисом,
  но ручное закрытие и повторный запуск всего продукта с новым вводом пароля (T41)
  нужно пройти пользователю по HANDOFF.
- Проверка InstanceLease выполнена отдельным потоком Windows. Второй продуктовый
  процесс с ручным закрытием диалога отказа не проверялся.
- Visual Studio 2022 не запускалась; сборка выполнена CLI SDK 10.0.103 с target net8.0
  и runtime 8.0.24. Для VS2022 нужен установленный совместимый SDK .NET 8.
- Снимки docs/screenshots получены RenderTargetBitmap с содержимого реально открытых
  WPF-окон после layout. Это не захват рабочего стола через системный Computer Use.
- Один человек, одна порция, три приема в день; только граммы, BYN и учебные цены.
  Медицинских рекомендаций, интеграции магазинов, семейных порций, экспорта чеков и ML нет.
- Каталоги общие для установки. Локальная авторизация не шифрует SQLite и не заменяет
  права Windows на файл; восстановление пароля и удаление аккаунтов не входят в объем.
- Генератор ограничен 100000 узлов; эвристики не гарантируют разнообразие, оптимум
  закупок или точное попадание БЖУ. SearchLimitReached не доказывает отсутствие решения.
- Отмена уже совершенного приготовления, резервирование для других недель и
  автоматическое пополнение по покупкам не предусмотрены контрактом.
- Внешнее одновременное редактирование файла БД не поддерживается. Общая блокировка
  рассчитана на один экземпляр приложения и один DatabaseRuntime для этого файла.
- Формы показывают ошибку с названием поля внизу, без отдельной подсветки каждого поля.
  Непредвиденная ошибка не раскрывает stack trace пользователю; технический журнал
  содержит только тип/стек без введенных значений.
- Итоговый Word не создавался. СТП 01–2024 целиком не предоставлен; соответствие
  оформления Word не заявляется. Согласование с публичным commit еще не проводилось.
- Код и тесты зафиксированы в `eaca1373111486bccd7d6e03be66e960cd4fb828`;
  документация добавлена следующим коммитом. Публикация `main` разрешена владельцем;
  независимая сверка будущего Word с этим срезом еще не проводилась.

Ручная приемка перед защитой: заполнить профиль, зарегистрироваться и войти через
PasswordBox, проверить формы/удаления/подтверждения, закрыть и открыть приложение,
убедиться в сохранении меню/остатков, проверить второй процесс на тот же путь.
