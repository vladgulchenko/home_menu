## Запуск

Windows, .NET Desktop Runtime 8; для сборки совместимый SDK и workload классических .NET-приложений. Открыть HomeMenu.sln, стартовый проект HomeMenu.Wpf. Терминал:

```powershell
dotnet restore HomeMenu.sln --locked-mode
dotnet run --project src/HomeMenu.Wpf/HomeMenu.Wpf.csproj -c Release
```

Обычная БД: `%LOCALAPPDATA%\HomeMenuCourse\homemenu.db`. Для отдельной демонстрации перед запуском задать HOMEMENU_DATABASE_PATH на новый файл. Seed создаёт 17 продуктов и 9 рецептов, учётных записей нет: нужно зарегистрироваться.
