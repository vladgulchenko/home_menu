# Исходники схем

| Файл | Содержание |
| --- | --- |
| architecture.mmd | Зависимости слоев и точка композиции |
| classes.mmd | Все девять предметных классов и кратности |
| database.mmd | Ключи и связи физических таблиц; полные столбцы/SQL — DATABASE.md |
| use-cases.puml | Работающие варианты использования одного типа пользователя |
| generation.mmd | Конечный поиск, ошибки, отмена, проверка актуальности, атомарная запись |
| cooking.mmd | Подтверждение, FEFO, полный отказ при дефиците, commit |
| shopping.mmd | Неприготовленные блюда, распределение запасов по датам, текущие цены |

Файлы mmd используют Mermaid, puml — PlantUML с нативными use cases.
Окончательная нумерация рисунков не назначена. В diagram classes кратность 21
относится к сервисной гарантии генерации, не к одному FK или CHECK.
Схемы исходной первой работы сохранены в sources/figures; новые схемы учитывают
уточнения гайда. Финальная верстка схем в Word выполняется отдельно.
